# Formate

> **Status:** Entwurf — abgeleitet aus [00-konzept.md](00-konzept.md).

Der Kanal fährt drei Formate. Jedes hat eine eigene Vorlage in [`templates/`](../templates/).

## 1. The Finest Part (Hauptformat)

| | |
|---|---|
| Länge | 6–10 Minuten |
| Gegenstand | ein Spiel, ein Abschnitt (oder bis zu 3 Abschnitte) |
| Struktur | 6 Kapitel, siehe [00-konzept.md](00-konzept.md#grundstruktur) |
| Vorlage | [`templates/skript-vorlage.md`](../templates/skript-vorlage.md) |
| Titelmuster | `The Finest Part of <Spiel>` |

Das Rückgrat des Kanals. Die Kapitel 1–6 sind gesetzt, die Zeitmarken sind Richtwerte — ein 7-Minuten-Video verkürzt Kapitel 3 und 5 proportional, statt Kapitel zu streichen.

**Variante „3 Abschnitte":** Kapitel 2–4 werden dreimal in Kurzform durchlaufen, Kapitel 5 fasst übergreifend zusammen. Nur einsetzen, wenn ein Spiel wirklich mehrere gleichstarke Kandidaten hat.

## 2. The Finest Moment (Kurzformat)

| | |
|---|---|
| Länge | 1–3 Minuten |
| Gegenstand | ein einzelner herausragender Moment |
| Struktur | Hook → minimaler Kontext → warum es funktioniert → wirken lassen |
| Vorlage | [`templates/shorts-vorlage.md`](../templates/shorts-vorlage.md) |
| Titelmuster | `The Finest Moment in <Spiel>` |

Kein verkürztes Hauptvideo, sondern eine eigene Erzählform: ein einziger Gedanke, sauber ausgeführt.

## 3. Shorts (max. 60 Sekunden)

| | |
|---|---|
| Länge | ≤ 60 Sekunden, 9:16 |
| Zweck | Reichweite und Kanal-Aufmerksamkeit |
| Vorlage | [`templates/shorts-vorlage.md`](../templates/shorts-vorlage.md) |

Zwei Quellen für Shorts:

1. **Abgeleitet:** ein in sich geschlossener Ausschnitt aus einem Hauptvideo (nicht der Trailer davon, sondern ein eigenständiger Gedanke).
2. **Eigenständig:** ein Moment, der für ein Hauptvideo zu klein ist.

Regeln:

- die ersten 2 Sekunden zeigen Bewegung oder ein starkes Bild, nie ein Textinsert allein
- eine Aussage pro Short
- kein „Ganzes Video im Kanal"-Overlay über dem ganzen Short; höchstens am Ende dezent
- das 9:16-Framing wird beim Schnitt geprüft, nicht nachträglich zugeschnitten

## Abgrenzung

| Frage | Format |
|---|---|
| Trägt der Abschnitt 6+ Minuten Analyse? | The Finest Part |
| Ist es ein einzelner Moment mit einem Gedanken? | The Finest Moment |
| Funktioniert es ohne jeden Kontext in 30–60 Sek.? | Short |
