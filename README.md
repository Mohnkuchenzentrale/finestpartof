# FinestPartOf

Arbeitsrepository für den YouTube-Kanal **FinestPartOf** — *The finest part of every game.*

Jedes Video widmet sich einem Spiel und dem einen Abschnitt, der es besonders macht. Hier liegen Konzept, Richtlinien, Vorlagen und alle Videoinhalte als Markdown.

## Ein neues Video anlegen

1. Kandidat aus dem [Ideen-Backlog](content/ideen-backlog.md) wählen
2. Ordner `content/videos/<nr>-<slug>/` anlegen, Vorlagen aus [`templates/`](templates/) hineinkopieren
3. Zeile im [Redaktionsplan](content/redaktionsplan.md) ergänzen
4. Dem [Workflow](docs/04-produktionsworkflow.md) folgen

## Konventionen

- **Arbeitssprache im Repo:** Deutsch. **Sprache im Video:** Englisch.
- Kein Videomaterial, keine Binärdateien im Repo — nur Text.
- Das Konzept wird zuerst im Google Doc geändert, dann hier nachgezogen.
