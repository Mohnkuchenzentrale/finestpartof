# Ideen-Backlog

Auswertung der [gespielten Spiele](gespielte-spiele.md) (531 Titel) gegen das [Kanalkonzept](../docs/00-konzept.md).
Was hier steht, ist ein Vorschlag zur Diskussion — die endgültige Auswahl trifft Michael.

## Bewertungsraster

Ein Spiel ist ein guter Kandidat, wenn möglichst viele Punkte zutreffen:

| Kriterium | Frage |
|---|---|
| **Abgrenzbar** | Lässt sich der Finest Part klar benennen („Kapitel X", „das Level Y")? |
| **Wortlos erklärbar** | Funktioniert die These mit wenig On-Screen-Text? |
| **Bildstark** | Trägt das Material Kapitel 4 („wirken lassen") ohne Text? |
| **Kontrast** | Bricht der Abschnitt mit dem Rest des Spiels? (Konzept nennt das explizit) |
| **Aufnehmbar** | Auf einer Plattform verfügbar, die sich sauber capturen lässt? |
| **Content-ID** | Wie hoch ist das Risiko bei Musik/Publisher? |

## Was aus dem Pool rausfällt — und warum

Rund zwei Drittel der Liste scheiden konzeptbedingt aus. Das ist kein Qualitätsurteil, sondern eine Formatfrage:

- **Roguelikes / prozedurale Spiele** (Hades, Dead Cells, Risk of Rain 2, Spelunky 2, Enter the Gungeon, FTL, Slay the Spire …) — es gibt keinen festen Abschnitt, den man zeigen kann. Ein Finest Part braucht einen Ort, den jeder Spieler an derselben Stelle erlebt hat.
- **Multiplayer & Kompetitives** (Counter-Strike, Rocket League, Smash Bros., Hearthstone, Heroes of the Storm, Vermintide …) — kein autorenschaftlicher Moment.
- **Simulation & Aufbau** (Cities: Skylines, Anno, Factorio, Die Sims, Theme Hospital, Transport Tycoon …) — kein erzählter Abschnitt.
- **Sport & Rennen ohne Kampagne** (FIFA, ISS, Mario Kart, Destruction Derby …)
- **Sammlungen / Ports ohne eigenen Inhalt** (Super Mario All-Stars, N. Sane Trilogy …) — besser das Originalspiel wählen.

Ausnahmen sind denkbar, brauchen aber eine sehr gute Begründung.

### Die drei besten SNES-Kandidaten

#### A — Super Metroid: die Ankunft auf Zebes

| | |
|---|---|
| Finest Part | die ersten Minuten auf Crateria, vom Landeanflug bis zum Abstieg ins verlassene Brinstar |
| Kontrast | ★★★ — ein Actionspiel beginnt mit mehreren Minuten, in denen nichts passiert |
| Wortlos erklärbar | ★★★ |
| Content-ID | **hoch** (Nintendo) |

**Warum es funktioniert:** Regen, ein leerer Planet, kein Gegner, kaum Musik — das Spiel lässt einen zuerst allein. Die Orte sind wiedererkennbar aus dem Vorgänger, aber tot. Das ist exakt die Sorte Abschnitt, für die dieser Kanal gebaut ist: Kapitel 4 („den Moment wirken lassen") ist hier praktisch das ganze Material, und die These lässt sich in drei Sätzen sagen.

**Der Haken:** Nintendo-Material gilt als das heikelste im ganzen Pool. Wie streng heute tatsächlich geclaimt wird, weiß ich nicht belastbar — das muss vor der Produktion mit einem privaten Testupload geprüft werden, nicht vermutet.

#### B — Donkey Kong Country 2: Bramble Blast

| | |
|---|---|
| Finest Part | das erste Dornenlevel mit „Stickerbrush Symphony" (David Wise) |
| Kontrast | ★★★ — ein bunter Plattformer wird für ein Level melancholisch und weit |
| Wortlos erklärbar | ★★★ |
| Content-ID | **hoch** (Nintendo, und das Thema *ist* die Musik) |

**Warum es funktioniert:** Ein Level, an das sich fast jeder erinnert — und fast niemand erinnert sich ans Springen darin. Die Musik verschiebt die Bedeutung des Ortes, ohne dass das Spiel einen Kommentar dazu abgibt. Perfekt für einen Kanal ohne Sprecher.

**Der Haken:** Das Argument steht und fällt mit der Tonspur. Wenn genau die geclaimt oder stummgeschaltet wird, ist das Video kaputt. Höheres Risiko als A, weil die Musik nicht nur Beiwerk, sondern Gegenstand ist.

#### C — Mega Man X: die Intro-Stage

| | |
|---|---|
| Finest Part | die Autobahn-Stage bis zum Kampf gegen Vile |
| Kontrast | ★★ |
| Wortlos erklärbar | ★★ |
| Content-ID | mittel (Capcom) |

**Warum es funktioniert:** Ein Level bringt einem wortlos jede Mechanik bei — inklusive des Wandsprungs, den niemand erklärt, den aber jeder lernt, weil die Levelarchitektur einen dazu zwingt. Und es endet mit einem Kampf, den man nicht gewinnen kann. Sehr konkretes Material für Kapitel 3.

**Der Haken:** Dieses Thema ist auf YouTube schon oft behandelt worden. Kein Ausschlussgrund — aber du bräuchtest einen eigenen Blickwinkel, sonst ist es das vierte Video über dieselbe Beobachtung.

### Meine Empfehlung

**A — Super Metroid**, weil kein anderer SNES-Titel im Pool so genau das ist, was der Kanal sein will: ein Abschnitt, der ohne ein einziges Wort funktioniert. C ist die risikoärmere Wahl, wenn du beim ersten Video kein Rechtethema willst.

Falls A: den Content-ID-Test als eigenen Schritt **vor** dem Schnitt einplanen, nicht danach. Ein kurzer privater Testupload mit Rohmaterial und Originalton reicht.

## Shortlist — die 12 stärksten Kandidaten

Sortiert nach Eignung fürs Format, nicht nach Qualität der Spiele.

### 1. Half-Life 2 — Ravenholm

| | |
|---|---|
| Jahr / Plattform | 2004, PC |
| Finest Part | das Kapitel „We Don't Go To Ravenholm…" |
| Kontrast | ★★★ — ein Horrorkapitel mitten in einem Action-Shooter |
| Aufnehmbar | sehr leicht (Steam, PC, moderne Auflösungen) |
| Content-ID | gering |

Das Musterbeispiel des ganzen Kanalkonzepts: ein Spiel wechselt für eine Stunde vollständig das Genre — anderes Tempo, andere Waffe (Gravity Gun statt Munition), andere Tonspur (fast nur Umgebungsgeräusche). **Warum es funktioniert:** Ressourcenknappheit und Fallenlogik zwingen einen anderen Spielstil auf, ohne es je zu erklären. Grigori als einzige Stimme. Perfektes Kapitel 4: Ravenholm bei Nacht braucht keinen Text.

### 2. What Remains of Edith Finch — Lewis' Kapitel

| | |
|---|---|
| Jahr / Plattform | 2017, PC/Konsole |
| Finest Part | die Fischfabrik-Sequenz (Lewis) |
| Kontrast | ★★★ — Splitscreen zwischen Fließbandarbeit und Tagtraum |
| Aufnehmbar | sehr leicht, kurzes Spiel |
| Content-ID | gering |

Der wohl meistzitierte „ein Kapitel, das alles trägt"-Moment der letzten zehn Jahre. **Warum es funktioniert:** Die Mechanik selbst erzählt — die linke Hand macht monotone Arbeit, die rechte eine Fantasiewelt, und das Verhältnis kippt langsam. Das lässt sich in wenigen Sätzen erklären und muss danach nur noch gezeigt werden. Für einen jungen Kanal ideal, weil das Spiel kurz ist und die These sofort einleuchtet.

> **Spoilerhinweis:** Der Ausgang von Lewis' Geschichte darf nicht in Titel/Thumbnail.

### 3. Vampire: The Masquerade – Bloodlines — Ocean House Hotel

| | |
|---|---|
| Jahr / Plattform | 2004, PC |
| Finest Part | die Spukhaus-Quest im Ocean House Hotel |
| Kontrast | ★★★ — waffenlose Geisterhaus-Sequenz in einem RPG |
| Aufnehmbar | mittel (alter Titel, Community-Patch empfohlen) |
| Content-ID | gering |

Genau der Fall, den das Konzept beschreibt: ein technisch brüchiges Spiel mit einem herausragenden Abschnitt. **Warum es funktioniert:** kein Gegner, nur Scripted Events, Geräusche und ein Haus, das sich gegen einen wendet — und der Spieler hat ausgerechnet hier all seine Vampirkräfte, die nichts nützen. Starkes Argument fürs „ein Spiel muss nicht perfekt sein"-Thema.

### 4. Ōkami — Wiederbelebung der Landschaft (Hana Valley / Guardian Saplings)

| | |
|---|---|
| Jahr / Plattform | 2006, Remaster auf PC/Konsole |
| Finest Part | der erste Moment, in dem die Farbe in die Welt zurückkehrt |
| Kontrast | ★★ |
| Aufnehmbar | leicht (HD-Remaster) |
| Content-ID | gering–mittel (Capcom, OST) |

Der visuell stärkste Kandidat im Pool. **Warum es funktioniert:** Hier braucht es fast keinen Text — Kapitel 4 schreibt sich von selbst. Gut als zweites oder drittes Video, wenn der Kanal zeigen soll, dass er auch rein bildlich erzählen kann.

### 5. Call of Duty 4: Modern Warfare — All Ghillied Up

| | |
|---|---|
| Jahr / Plattform | 2007, PC/Konsole |
| Finest Part | die Pripjat-Rückblende |
| Kontrast | ★★★ — Schleichmission in der lautesten Shooter-Reihe überhaupt |
| Aufnehmbar | leicht (Remaster oder Original) |
| Content-ID | mittel (Activision) |

Ein Abschnitt, der eine ganze Serie überlebt hat. **Warum es funktioniert:** Das Spiel nimmt einem die Kernmechanik weg (Schießen) und ersetzt sie durch Warten. Die Szene im Gras, in der eine Patrouille über einen hinwegsteigt, ist das Gegenteil von allem, wofür die Reihe sonst steht.

### 6. Warcraft III: Reign of Chaos — Die Läuterung von Stratholme

| | |
|---|---|
| Jahr / Plattform | 2002, PC (Reforged-Fassung ist umstritten → Original bevorzugen) |
| Finest Part | die Kampagnenmission „The Culling" |
| Kontrast | ★★★ — moralische Entscheidung in einem RTS |
| Aufnehmbar | mittel (Original-Fassung beschaffen) |
| Content-ID | mittel (Blizzard) |

**Warum es funktioniert:** Ein Strategiespiel macht die Missionsmechanik selbst zum Argument — man muss die eigene Bevölkerung töten, unter Zeitdruck, während der Spielhinweis sachlich bleibt. Wenige Spiele haben eine Charakterwendung so vollständig ins Gameplay gelegt.

### 7. S.T.A.L.K.E.R.: Shadow of Chernobyl — Labor X-16

| | |
|---|---|
| Jahr / Plattform | 2007, PC |

| Aufnehmbar | leicht (PC, Mods für Auflösung) |
| Content-ID | gering |

**Warum es funktioniert:** Sounddesign und Psi-Effekte statt Gegner. Das Spiel entzieht einem die Orientierung, ohne je die Kamera zu übernehmen. Sehr guter Kandidat für ein Video, das über Ton argumentiert.

### 8. Metro 2033 — der Gang an die Oberfläche

| | |
|---|---|

### 9. Shadow of the Colossus — der erste (oder der dreizehnte) Koloss

**Warum es funktioniert:** Ein Spiel bringt einem in einer einzigen ununterbrochenen Szene bei, dass man nichts von dem glauben darf, was man sieht — und macht daraus die Grundregel für die nächsten 20 Stunden. Muss ohne Spoiler im Titel auskommen.
